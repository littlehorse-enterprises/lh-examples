# Docker Containers

This directory contains examples of how to build docker images containing LittleHorse Clients which can be used to register `WfSpec`s and run Task Workers.

* [Quarkus](./quarkus) is the first example, showing how to package a container using the `quarkus` CLI and the `littlehorse-quarkus` extension.

More examples coming soon, including Python, Go, C#, and vanilla Java.
